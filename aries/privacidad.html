Política de privacidad de Aries

Última actualización: 25 de octubre de 2026.

Qué datos usa

Aries accede a Google Calendar de la cuenta que lo autoriza para leer eventos y cumpleaños, y para crear o actualizar eventos del horario de clases.

Dónde se guardan

Los datos se procesan en la PC donde corre Aries. El permiso de acceso (token) se guarda solo en esa PC. Aries no tiene servidores propios y no envía los datos del calendario a terceros, no los vende ni los usa para publicidad.

Uso de datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede quitar en cualquier momento desde myaccount.google.com/permissions.
